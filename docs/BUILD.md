# Building and checking the library

Run the commands below from the directory containing `lakefile.toml`.

## Toolchain and dependencies

The committed `lean-toolchain` selects Lean `v4.32.0-rc1`. The Mathlib revision is pinned in `lakefile.toml`, and `lake-manifest.json` records all resolved dependencies. Keep these files together when checking out or distributing the source.

Git, Python 3, and `elan` with the `lake` command are needed. Fetch the dependency cache with:

```sh
lake exe cache get
```

## Full verification

```sh
bash scripts/check.sh
```

This command checks the source layout and local documentation links, runs `lake build`, and checks `Audit.lean` with `autoImplicit=false`. The audit visits declarations by both namespace and defining module, including private helpers, and checks their transitive logical dependencies against `propext`, `Classical.choice`, and `Quot.sound`.

A successful run writes `verification/check.log`, `verification/summary.json`, and `verification/source-manifest.json`. These generated files record the actual build, declaration counts, and hashes of the formal sources and build configuration. They are excluded from version control and regenerated by the check.

The [GitHub Actions workflow](../.github/workflows/lean.yml) installs the pinned toolchain, fetches the Mathlib cache, and runs the same verification command.

## Working with modules

The public entry point is [PlanarNikodym.lean](../PlanarNikodym.lean). Every library module is reachable from that import. Mathematical declarations live in the `PlanarNikodym` namespace; directories group the source by subject.

After adding or moving a module and updating the necessary imports, refresh the index:

```sh
python3 scripts/check_layout.py --write-index
bash scripts/check.sh
```

The result statements and their declarations are listed in [RESULTS.md](RESULTS.md). Preserve their hypotheses, parameter domains, exponent ranges, and quantifier order when changing an API.

## Source health and packaging

After full verification, collect a source and dependency inventory:

```sh
python3 scripts/audit_health.py --output verification/health-current.json
```

The inventory records source line counts, import duplication, dependency revisions and cleanliness, and checks for proof shortcuts and unsafe declarations.

To package a verified checkout:

```sh
python3 scripts/package.py --output ../PlanarNikodym-source.zip
```

The packager verifies that the sources match the last successful check and that the locked dependencies are clean. It writes a ZIP and its SHA-256 checksum, excluding Git metadata, dependency caches, and compiled objects.
